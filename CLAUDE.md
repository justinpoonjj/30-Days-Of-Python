# CLAUDE.md — 30 Days of Python

Course-along repo (Asabeneh's "30 Days of Python"). My practice solutions live in `my_solutions/`.

## Extracting a day's exercises

When asked to "extract Day N exercises into my_solutions/Day_N":

1. Find the day's exercise list in `NN_Day_<Topic>/NN_<topic>.md`, under the `## 💻 Exercises` section (may be split into Level 1/2/3).
2. Create `my_solutions/Day_N/Exercise_<level>.py` — one file per level. If the day has no levels, use a single `Exercise_1.py`.
3. **Copy each exercise as a numbered comment prompt, leave the answer BLANK.** These are for me to practice — do NOT solve them. Preserve any "Given data" snippets the exercise provides.
4. Header line: `# Day N - <Topic> | Exercises: Level X`.

Example shape:

```python
# Day 8 - Dictionaries | Exercises

# 1. Create an empty dictionary called dog


# 2. Add name, color, breed, legs, age to the dog dictionary

```

Reference `my_solutions/Day_7/` for the established format.
